### ✅ الطريقة الصحيحة

```
✓ افتح ملف جديد
✓ شغل Chrome
✓ ايش الوقت

```

### ❌ تجنب هذا

```
✗ هل يمكنك فتح ملف جديد (طويل جداً)
✗ افتح... ملف... جديد (توقفات طويلة)
```

### 💡 نصائح مهمة

1. **تحدث بوضوح** - النطق الصحيح أهم من السرعة
2. **استخدم جمل قصيرة** - أوامر بسيطة وواضحة
3. **انتظر حتى تنتهي** - اترك JARVIS يستمع كاملاً
4. **جرب التحرير النصي** - إذا لم يعمل الصوت

## 🎯 تخصيص الأوامر

### إضافة أمر جديد

اقرأ [DEVELOPMENT.md](DEVELOPMENT.md) لمعرفة كيفية:
1. إضافة intent جديد
2. كتابة معالج للأمر
3. اختبار الأمر

### مثال: إضافة أمر فتح موقع ويب

```python
# في command_processor.py
self.patterns = {
    IntentType.OPEN_WEBSITE: [
        r'(افتح|ادخل|زور).*موقع',
    ]
}

# في task_executor.py
async def _open_website(self, params):
    website = params.get('website')
    import webbrowser
    webbrowser.open(f"https://{website}.com")
    return f"✓ تم فتح {website}"
```

## 🐛 حل المشاكل

### المشكلة: "لم أفهم الأمر"

**الحل:**
1. تحدث بوضوح أكثر
2. استخدم أوامر بسيطة
3. جرب الإدخال النصي

### المشكلة: "الميكروفون لا يعمل"

**الحل:**
1. استخدم Chrome أو Edge
2. وافق على إذن الميكروفون
3. تحقق من مستوى صوت الميكروفون
4. جرب الإدخال النصي

### المشكلة: "البرنامج لا يفتح"

**الحل:**
1. تأكد من تثبيت البرنامج
2. استخدم اسم صحيح (chrome، word، notepad)
3. انظر سجلات Backend
